# Long Way Home

A five-species whale migration strategy game. The current desktop visual study
starts with an era timeline and five static holographic whale cards. Expeditions
use a live 3D ocean atlas and threats that change with the chosen era. UI copy and educational content are in English.

## Run on this Mac

```sh
/Users/WilliamFan/Downloads/Godot.app/Contents/MacOS/Godot --path /Users/WilliamFan/long-way-home
```

The project defaults to Godot 4 Forward+ with Metal on macOS. It has been rendered
and checked on the local Apple M2. Drag the expedition map to pan, scroll to zoom,
and use the field guide to see the larger static whale illustration. Choose an era
(1700s, 1800s, 1900s, 2000s, or a 2100 future scenario), then a species and Start
Migration. Drag the continuous time ruler left/right, use the wheel or trackpad, or use
arrow keys (Home/End reach the endpoints). The center marker stays fixed as years
scroll past. A loose group of large and small holographic whales fades smoothly
with time; the selected species supplies its artwork. Gameplay uses the century
containing the selected year, with 2100 reserved for the future scenario. Advance,
Forage and matching protections determine the journey. Settings contains persisted
reduced motion and fullscreen controls. Home returns to setup while preserving the
active expedition; Continue restores its era and species. Save schema v2 includes
an era and migrates valid v1 saves to the original 2000s rules.

## Scope of the visual study

This is an interactive desktop visual study, not a claim of final visual parity
with the Obsidian concept artwork. Whale portraits are AI-assisted holographic illustrations derived from the
Obsidian concept reference, with distinct assets for all five species. They are
visual studies, not validated anatomical plates. Original generated PNG alpha
is preserved; the full prompts and provenance are in
`assets/whale-image-prompts.json`. Portraits use ordinary 2D textures without
3D whale geometry, a whale viewport, or per-frame whale animation. Coastlines use Natural Earth
public-domain data. Relief is synthetic, not measured seabed topography. Routes
are population-specific educational simplifications. See SOURCES.md.

Forward+ cannot be exported directly to a web renderer. A web release needs a
Compatibility configuration and separate fidelity/performance checks. Web export
has not been validated for this visual study.

The earlier implementation is preserved under `backups/pre-hologram/`, ignored
by Godot imports. The pre-era UI and simulation are preserved in `backups/pre-era-selection/`.

The previous rotating-whale implementation is also preserved in
`backups/pre-static-whales/`.

## Era interpretation

Era threats and difficulty are authored educational scenarios, not reconstructed
population data. Fading silhouettes illustrate decline without counts; actual
trends include recoveries and vary by population. 2100 is explicitly a future
scenario, not a forecast. Historical protections are counterfactual choices.
Wrecks provisionally mean abandoned rigging and debris. Nine obstacle icons are
implemented; the blank tenth sketch slot remains unassigned.
